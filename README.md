\# Emergency Blood Bank Management System



\## Project Overview

Emergency Blood Bank Management System is a Java-based desktop application developed to manage blood donors and receivers.



\## Technologies Used

\- Java

\- Java Swing

\- Object-Oriented Programming (OOP)



\## Project Structure

\- Entity: Contains Admin, Donor, Receiver, and User classes.

\- EntityList: Contains classes for managing user and donor records.

\- GUI: Contains the graphical user interface.

\- GUI/Resources: Contains background images and icons.

\- Start.java: Main entry point of the application.



\## Features

\- Home page

\- Login interface

\- Donor management structure

\- Receiver management structure

\- Admin management structure



\## How to Run

1\. Install the Java Development Kit (JDK).

2\. Open the project folder.

3\. Run the Run.bat file on Windows.
